Attivazione venv su macchine di laboratorio: python3 -m venv llmrev 

Successivamente, per attivare l’ambiente virtuale: 
(Windows – cmd)       venv\Scripts\activate   
(Mac o Linux)         source venv/bin/activate  (Macchine laboratorio) -> source llmrev/bin/activate <-


Librerie MongoDB:
pip install pymongo werkzeug

pip install -r requirements.txt
